# 功能与使用

SiliconPlayer 0.6.0 日常版面向 Apple Silicon Mac。它将日常操作放在主窗口内：打开媒体、控制播放、选择字幕和音轨、管理列表，以及截图与导出。本页介绍已经完成本地构建与测试的应用行为；当前 GitHub 发布内容为源码、图文说明与测试摘要。

## 打开与播放

- **⌘O** 打开视频或音频；**⇧⌘O** 添加到列表。支持拖入媒体、多个文件和文件夹。
- **⌘U** 输入直接媒体网络地址。网页解析属于后续范围。
- 使用时间轴定位，或用 **← / →** 跳转 5 秒；**. / ,** 逐帧，**[ / ]** 调速。
- **A** 依次设置 A 点、B 点并清除循环。全屏与系统画中画可从窗口控制进入。

输入文字或选择列表项目时，按键优先用于编辑和列表选择，避免误触播放。列表右键提供“向上移动 / 向下移动”；物理拖动排序的本轮自动化验证受工具限制。

## 字幕、声音与画面

**⇧⌘S** 加载外部字幕，也可从字幕菜单选择内嵌字幕。主副字幕可以同时显示，分别设置位置、字体和延迟；多音轨与外部音轨从音频菜单选择。

播放设置包含六个分类，常用均衡器、画面调整和用户滤镜可按需启用。滤镜可能增加 CPU / GPU 负载，默认不启用。日常版不会自动应用完整开发配置中的 360°/3D、文件 LUT/GLSL、变调、高采样率或独占音频设置；原有持久化设置仍保留。

## 截图与导出

**⌘S** 保存截图。支持 PNG、JPEG、WebP 与剪贴板。截图默认位于 `~/Pictures/SiliconPlayer`。

“工具”中可手动生成时间缩略图与拼图，或导出 MP4 片段、原码复制片段及完整 WAV。WAV 保留输入采样率与声道，输出 16 位 PCM；使用 FFmpeg 默认源音轨选择，不保证跟随当前选中的音轨。片段起止时间不应用到完整 WAV。

时间轴拖动不自动生成缩略图，避免在普通定位时额外启动 FFmpeg。导出依赖已经包含在应用中。

## 数据保存

媒体库、偏好和播放记录位于 `~/Library/Application Support/SiliconPlayer`。列表筛选、多选、批量移除、导入导出、历史续播、书签和收藏用于日常整理。

本地成品自带播放与导出依赖，无需开发环境或语音模型。当前仅有 arm64 版本，最低目标 macOS 14；本轮实测设备与资源记录见 [测试摘要](TESTING.md)。源码构建需要先准备受控依赖，见 [开发说明](BUILDING.md)。
