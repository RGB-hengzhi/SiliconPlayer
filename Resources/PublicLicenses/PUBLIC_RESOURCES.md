# Public application legal resources

The original application is GPL-3.0-or-later. LICENSE and SiliconPlayer-LICENSE.txt contain the complete GNU GPLv3 text. NOTICE.md preserves original attribution, THIRD_PARTY.md summarizes component boundaries, and SOURCE_LINKS.txt points to corresponding-source assets.

Dependencies/ contains the final 125-file original notice collection; its manifest lists 124 source texts plus the manifest itself. runtime-to-source.json binds all 44 runtime libraries to exact source archives; license-selection.json and LICENSE_SELECTION.md record selected license alternatives. Existing third-party notices remain unchanged outside SCOPE.txt. Application 0.6.1 is a fresh source build with common playlist usability changes. Its playback libraries and tools retain the exact 0.6.0 bytes mapped here. Functional validation is recorded separately for each application version; earlier application test results are not inherited.
