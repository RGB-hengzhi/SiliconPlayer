# Third-party notices and publication scope

SiliconPlayer uses original Swift / SwiftUI / AppKit application code and integrates mature media projects. The application source has not yet been assigned a project-wide reuse license. Public visibility alone does not grant a new license. Third-party files retain their original copyright and license terms.

The six mpv API headers under Sources/CMPV and Sources/MetalRenderBridge preserve their inline ISC copyright, permission and disclaimer text. The SystemPiP bridge records its IINA API reference; that attribution is retained. Existing dependency license texts are retained under Vendor/licenses, Vendor/tools/licenses and Vendor/WebTools/licenses. Presence of a license document is not a statement that every optional dependency ships in the core application.

This repository publishes source, selected dependency metadata, documentation and original test-image screenshots. It does not distribute the local application, runtime libraries, helper binaries, speech models, downloaded test videos or raw workstation test records. Public binary distribution requires a complete linked-library inventory, corresponding source and build materials, and a compatible application licensing decision.

See [the development notes](Docs/BUILDING.md) for the current dependency and rebuild limits. No App Store, public notarization or complete GPL compatibility clearance is claimed.
