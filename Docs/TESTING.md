## 真实普通界面

两次自有应用阶段均正常关闭，日常设置与快捷键没有被测试改写。Root 的真实窗口观察确认：

- 启动欢迎页恢复两项列表和第二项 HEVC 标题，进度为零，播放控制与截图等未加载动作状态合理。
- 点击“继续上次”后，首次观察到约 8.167 秒并在播放；暂停在 23.133 秒。
- 使用 ⇧⌘O 添加 FLAC，列表增至三项，当前 HEVC、23.133 秒位置和暂停状态保持。
- 使用 ⌘O 打开 H.264，列表替换为一项；停止返回普通欢迎页，不再残留“已恢复”提示；⌘Q 正常退出。

这组真实界面记录独立于自动 152 项，不增加自动场景计数。它验证了按钮、保存/恢复和普通打开/追加路径；**没有把物理跨 App 拖动认证为通过**。
